# 文稿盒：第一版设计

日期：2026-10-29（Asia/Shanghai）
状态：用户已明确回复“确认”，设计批准；第一版已实现，本地验收见 docs/QA.md。

## 1. 产品目标

做一个中文优先的独立网页工具：用户粘贴 Markdown 格式的 AI 回答或自己的文字，查看排版预览，再下载可编辑的 Word（.docx）文件。用户不需要安装 Skill、登录账号或提供模型 API Key。

目标用户是要整理课程作业、会议记录、技术说明的学生及普通文档使用者。第一版强调容易理解的操作流程，不宣称自动校验内容、不生成论文、不保证课程评分或 GitHub Star 数。

## 2. 核心操作流程

1. 打开页面，可先点击“载入示例”了解效果；已有输入时替换内容需确认。
2. 在输入框粘贴或编辑 Markdown 纯文本。
3. 选择“普通文档”或“课程报告”排版，查看右侧预览。
4. 输入导出文件名，点击“下载 Word”。生成的文件可在文字处理软件中继续编辑。
5. 空输入、超出上限、转换失败时显示中文提示，不生成看似成功的空白文件。

预览用于检查文本、层级和样式，不承诺与 Word 的分页、字体替换及每一像素完全一致。

## 3. 第一版支持范围

- 中文界面：桌面采用输入与预览双栏，小屏上下排列。
- Markdown 一级至六级标题、普通段落、加粗、斜体。
- 有序列表、无序列表，最多三级嵌套；超过深度时给出明确提示。
- 常见 Markdown 管道表格，第一行为表头；暂不支持合并单元格。
- 行内代码和围栏代码块；代码作为文本保留，不执行代码。
- 引用段落和水平分隔线。
- 两套排版参数：普通文档适合日常记录；课程报告使用较正式的中文标题、正文和段落间距。两者均采用 A4 纸张，不伪造学校格式标准。
- 自带一个覆盖标题、列表、表格、代码的中文示例，便于立即体验。
- 文件名移除路径分隔符和不安全字符；空文件名使用默认名称。

第一版输入限制：最多 100,000 个字符、500 个块级元素；表格最多 30 列、200 行。超限必须提示用户缩小输入，不静默截断内容。

## 4. 明确不做

- 不接入任何模型，不自动生成正文或替用户核查事实。
- 不抓取聊天平台，不登录第三方网站，不导入聊天账号数据。
- 不支持 LaTeX 公式转换为 Word 公式，不处理复杂图表或任意 Word 模板。
- 不下载或嵌入远程图片；遇到 Markdown 图片标记时保留可读说明并提示未嵌入。
- 原始 HTML 按文字显示，不执行脚本、不创建其中的页面元素。
- 不提供云端存储、多人协作、用户账号、统计追踪或付费功能。
- 不自动保存用户文稿到浏览器持久存储；刷新前提醒用户留意未导出的输入。

## 5. 数据与安全边界

文稿内容仅在当前浏览器内存中解析与导出，不向服务器上传正文。托管方仍会收到正常页面与静态资源访问请求，因此不宣传“完全没有网络请求”。

发布版本将运行依赖打包为本站静态资源，不通过外部 CDN、远程字体、图片或统计脚本加载资源。页面资源加载完成后，输入、预览和导出不依赖在线服务。

Markdown 链接保留标签与地址文本，不在预览中创建可执行链接。原始 HTML、危险 URL、脚本片段作为文字处理。文档导出不创建远程图片关系、不插入宏、不执行命令。

对不支持的内容尽可能保留原始文字并显示提示；不得静默删除用户正文。非支持语法不承诺全部能自动识别，README 必须列明已知限制。

## 6. 实现结构

独立静态前端，不需要后端。采用 JavaScript 模块和轻量构建流程；Markdown 解析与 DOCX 生成使用经验证、许可证允许的开源依赖，实际版本在实现时核实并锁定。

模块边界：

- 输入解析：Markdown → 受限的统一文档结构，并生成转换提示。
- 文档预览：读取统一结构，通过安全 DOM API 构造预览，不直接注入用户 HTML。
- Word 导出：读取同一结构及模板参数，生成段落、列表、表格与代码样式。
- 排版模板：集中管理字体、字号、页边距、段落与表格样式。
- 页面交互：管理输入、模板、文件名、状态提示和下载，不参与格式转换规则。

解析和导出异常均显示中文错误；导出期间禁止重复触发，完成或失败后恢复按钮。大输入采用防抖更新预览。两个渲染端共用同一内容结构，减少预览和文件的内容差异。

## 7. 验收标准

- 从内置示例一键生成 .docx，导出文件包含示例全文、正确的标题层级、列表、表格及代码文本。
- 解包检查 DOCX 的必要 XML 和样式；检验中文与特殊字符保留，不把“下载成功”当作“格式正确”。
- 测试空输入、超限输入、嵌套列表、空表格单元格、代码中 HTML、恶意链接和文件名。
- 浏览器测试输入、切换模板、示例替换确认、中文错误提示、下载动作和手机宽度布局。
- 检查页面加载后处理文稿期间无正文上传或外部资源请求。
- 使用可用的文档渲染工具检查导出文件；测试记录准确写明已验证的软件与环境，不虚称所有 Word/WPS 版本兼容。
- 提供中文 README、英文简要入口、实际截图、测试命令、许可证说明和静态部署步骤。
